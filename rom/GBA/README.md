# Game Boy Advance games

Put each game in its own folder here, named after the game:

```
rom/GBA/My Game/My Game.zip
```

- The folder name is the game's title in the launcher.
- Too big to upload in one piece? Split it and upload the parts to the same folder: `My Game.zip.001`, `My Game.zip.002`, ... The launcher joins them back together.
- Add a `.jpg` or `.png` to the folder and it becomes the cover.
