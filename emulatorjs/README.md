# EmulatorJS (bundled)

[EmulatorJS](https://github.com/EmulatorJS/EmulatorJS) 4.2.3 with the melonDS, mupen64plus_next, mGBA, Gambatte, Snes9x, Genesis Plus GX, PCSX ReARMed, PPSSPP, PicoDrive (32X), Yabause (Saturn), Virtual Jaguar, Mednafen WonderSwan and Mednafen PCE cores, used by `emu.html`. Licensed under GPL-3.0 (see `LICENSE`).

`embed/` holds base64 copies of the files EmulatorJS downloads at runtime (core, report, decompressors). They are generated by `tools/embed-emulatorjs.py` and are only used when the launcher is opened from disk (`file://`), where browsers block normal downloads.

The PPSSPP (PSP) core (`data/cores/ppsspp-thread-wasm.data`, `ppsspp-assets.zip`) comes from the npm package `@emulatorjs/core-ppsspp` 4.2.3. PPSSPP is licensed under GPL-2.0 or later; source: https://github.com/EmulatorJS/ppsspp. It has no `embed/` copy, because PSP games can't run from `file://`.

`data/src/emulator.js` has two Fruti changes so a loaded game isn't copied again in memory (big PSP games need this on computers with little memory): game files are written to the emulator's file system with `canOwn: true`, and game data that is already a `Uint8Array` isn't wrapped in a new (copied) one.

The Saturn, Atari 2600 / 7800, Jaguar, Neo Geo Pocket, WonderSwan, Virtual Boy, PC Engine and 32X cores come from the npm packages `@emulatorjs/core-*` 4.2.3 (each core's license is inside its .data file). `data/src/emulator.js` also lists genesis_plus_gx first for the Master System, because smsplus isn't bundled.
